# 🎨 FastQuest - Design & UI Assets

Este repositório é dedicado ao armazenamento, versionamento e organização dos recursos visuais (telas, componentes e protótipos) da plataforma **FastQuest**, um banco de questões preparatórias para o Exame de Ordem da OAB.

---

## 📁 Estrutura de Diretórios

As interfaces foram organizadas por plataforma e divididas conforme as rotas e contextos de uso da aplicação. Todos os arquivos visuais e protótipos são versionados exclusivamente em formato `.svg`.

```text
📁 design
├── 📁 mobile/
│   ├── 📁 auth/          # Telas de Login, Registro e Recuperação de Senha
│   ├── 📁 home/          # Dashboard inicial e Feed da versão Mobile
│   ├── 📁 questoes/      # Listagem de questões, Tela de Resolução e Gabarito
│   ├── 📁 listas/        # Criação, Edição e Visualização de listas salvas
│   └── 📁 perfil/        # Configurações do usuário e Histórico
│
└── 📁 web/
    ├── 📁 auth/          # Autenticação e Gestão de Contas (Desktop)
    ├── 📁 home/          # Visão geral
    ├── 📁 questoes/      # Banco de questões, Filtros e Resolução
    ├── 📁 listas/        # Gerenciamento de listas e simulados
    └── 📁 perfil/        # Painel do perfil e Métricas de Desempenho
